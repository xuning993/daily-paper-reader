## 摘要
多任务车辆路径规划问题（VRPs）旨在满足多种约束的同时最小化路径成本。现有的求解器通常采用统一的强化学习（RL）框架来学习跨任务的可泛化模式。然而，它们往往忽略了决策过程中的约束和节点动态，导致模型无法准确地对当前上下文做出反应。为了解决这一局限性，我们提出了上下文链学习（Chain-of-Context Learning, CCL），这是一个逐步捕获演化上下文以引导细粒度节点自适应的新型框架。具体而言，CCL 通过相关性引导的上下文重构（Relevance-Guided Context Reformulation, RGCR）模块构建逐步的上下文信息，该模块能够自适应地优先处理显著约束。随后，该上下文通过轨迹共享节点重嵌入（Trajectory-Shared Node Re-embedding, TSNR）模块引导节点更新，该模块聚合来自所有轨迹上下文的共享节点特征，并将其用于更新下一步的输入。通过对强化学习智能体不断演化的偏好进行建模，CCL 捕获了序列决策中的逐步依赖关系。我们在 48 种不同的 VRP 变体上评估了 CCL，包括 16 个分布内任务和 32 个分布外（包含未见约束）任务。实验结果表明，CCL 的表现优于最先进的基准模型，在所有分布内任务和大多数分布外任务上均取得了最佳性能。

## Abstract
Multi-task Vehicle Routing Problems (VRPs) aim to minimize routing costs while satisfying diverse constraints. Existing solvers typically adopt a unified reinforcement learning (RL) framework to learn generalizable patterns across tasks. However, they often overlook the constraint and node dynamics during the decision process, making the model fail to accurately react to the current context. To address this limitation, we propose Chain-of-Context Learning (CCL), a novel framework that progressively captures the evolving context to guide fine-grained node adaptation. Specifically, CCL constructs step-wise contextual information via a Relevance-Guided Context Reformulation (RGCR) module, which adaptively prioritizes salient constraints. This context then guides node updates through a Trajectory-Shared Node Re-embedding (TSNR) module, which aggregates shared node features from all trajectories' contexts and uses them to update inputs for the next step. By modeling evolving preferences of the RL agent, CCL captures step-by-step dependencies in sequential decision-making. We evaluate CCL on 48 diverse VRP variants, including 16 in-distribution and 32 out-of-distribution (with unseen constraints) tasks. Experimental results show that CCL performs favorably against the state-of-the-art baselines, achieving the best performance on all in-distribution tasks and the majority of out-of-distribution tasks.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：现有的多任务车辆路径规划（VRP）神经求解器通常采用静态节点嵌入（Static Node Embeddings），即在整个解码过程中节点特征保持不变。
*   **研究动机**：在处理包含多种约束（如时间窗、回程需求等）的复杂VRP时，节点的“紧迫性”或“重要性”会随着车辆状态（剩余容量、当前时间、已行驶距离）的改变而动态演化。静态嵌入无法捕捉这种动态性，导致模型在决策时无法准确响应当前的约束状态。
*   **整体含义**：本文旨在建立一种“上下文链学习”（CCL）框架，通过在解码的每一步动态更新节点表示和上下文信息，实现对多约束环境的细粒度感知。

### 2. 方法论：核心思想与关键技术
CCL 框架通过两个核心模块在解码阶段（MDP 过程）实现动态推理：
*   **相关性引导的上下文重构（RGCR）**：
    *   **思想**：并非所有约束在每一步都同样重要。
    *   **实现**：提取当前轨迹的约束属性（如剩余容量、当前时间），计算各约束嵌入与当前节点嵌入的相关性得分（点积），据此自适应地加权聚合约束特征，生成增强的上下文向量。
*   **轨迹共享节点重嵌入（TSNR）**：
    *   **思想**：解决动态重嵌入带来的高计算开销。
    *   **实现**：利用多头注意力机制，将所有并行轨迹的上下文作为 Key 和 Value，将共享的节点嵌入作为 Query。这样，模型可以在不为每条轨迹独立重新编码所有节点的情况下，吸收多轨迹的上下文语义，实现高效的节点特征更新。
*   **上下文链（Chain-of-Context）**：
    *   更新后的节点嵌入会反馈到下一步的上下文构造中，形成时间步间的依赖链，从而建模智能体演化的偏好。

### 6 主要结论与发现
*   **性能领先**：CCL 在所有 16 个 ID 任务和绝大多数 OOD 任务中均优于现有 SOTA（如 CaDA），尤其在带时间窗（TW）的复杂任务中优势巨大。
*   **泛化能力**：在未见过的约束组合（如 MDVRP）和更大规模（N=600）的真实世界实例（Solomon, Homberger）上展现了极强的零次泛化性能。
*   **动态性价值**：实验证明，在解码过程中动态更新节点状态对于准确估计马尔可夫决策过程（MDP）的状态至关重要。

### 7. 优点
*   **细粒度感知**：通过 RGCR 解决了多约束环境下权重分配的问题，使模型能“聚焦”于当前最紧迫的约束。
*   **计算效率优化**：TSNR 模块巧妙地利用轨迹共享机制，克服了传统动态重嵌入方法（如 ASW-TAM）计算量过大的缺陷。
*   **即插即用**：该策略可以集成到多种基础编码器架构中，具有良好的通用性。

### 8. 不足与局限
*   **推理延迟**：相比于完全静态的神经求解器（如 CaDA），CCL 由于增加了每一步的重嵌入计算，推理时间有所增加（约慢 2-3 倍）。
*   **超参数敏感性**：测试时的更新概率 $P_{ts}$ 需要根据具体任务在性能和速度之间进行权衡，虽然提供了灵活性，但也增加了调参成本。
*   **训练稳定性**：在某些非坐标输入的场景（如 FFSP 调度问题）中，训练表现出一定的波动性，暗示该方法在非几何结构问题上的鲁棒性仍有提升空间。
